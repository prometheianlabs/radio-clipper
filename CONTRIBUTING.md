# Contributing

## Workflow

- Create a focused branch for each change.
- Prefer pull requests over direct pushes when practical.
- Keep changes surgical and update docs when behavior or scope changes.

## Before opening a PR

- Run the relevant local checks for the area you touched.
- Fill out the pull request template completely.
- Call out any deploy, config, or secret impact.

## Issues

- Use the provided issue templates.
- Review the repository README and planning context before filing a new issue.
- Prefer one issue per discrete bug, feature, or follow-up.
