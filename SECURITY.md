# Security Policy

## Reporting a vulnerability

Do not open a public issue with exploit details, credentials, or sensitive operational information.

If you find a security issue:

- contact the repository owner privately if you already have a trusted channel
- otherwise open a minimal GitHub issue that states a private security report is needed, without including the vulnerability details
- rotate any exposed credentials immediately

## Scope

Security-sensitive changes include authentication, secrets, infrastructure bindings, file access, upload flows, and anything that changes trust boundaries.
